чувствовать себя комфортнее. Структура будет примерно такая:
- `src` - тут будет лежать приложение
- `public` - точка входа
- `templates` - frontend
- `lib` - сюда положу smarty
- `database` - sql и сиды
- `.env/.env.example` - для хранения подключения к базе
